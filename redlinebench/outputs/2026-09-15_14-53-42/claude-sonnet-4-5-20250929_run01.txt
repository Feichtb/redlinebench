# Architectural Document Review: Bonfire House

## Project Context

**Project:** Bonfire House, Chatham County, North Carolina  
**Code Jurisdiction:** 2018 North Carolina Residential Code (IRC 2015 with amendments)  
**Building Type:** Single-family residence (R-3 occupancy)  
**Construction Type:** V-B  
**Climate Zone:** 4A (mixed-humid)  
**Scope:** 4-bedroom, 3.5-bath, 2-story house with attached garage, 3,270 SF heated, 3,840 SF total; includes lap pool, deck, and site work  

**Drawing Set Included:** Complete architectural set (34 sheets) — general, site, floor plans, elevations, sections, details, schedules; no structural, MEP, or civil drawings provided  
**Specifications Included:** Yes, 11-page narrative specifications document

## Summary

This bid set exhibits a level of development appropriate for residential construction but contains **critical deficiencies that will generate RFIs, change orders, and potential code compliance failures** if not resolved before bidding.

**Top Three Areas of Concern:**

1. **Code and Life Safety Violations:** Both interior stairs are dimensioned with riser heights (9" and 12") that substantially exceed the IRC maximum of 7-3/4", making them unbuildable as drawn. Garage separation details omit required fire-rated assemblies and self-closing door hardware. Emergency escape window verification is absent. These are not minor coordination gaps — they are fundamental code violations that would fail inspection.

2. **Building Envelope Coordination Failures:** The exterior wall insulation system shows conflicts between specifications (ZIP Board, 1" rigid insulation) and details (plywood sheathing, 1.5" rigid insulation), with a weather barrier positioned in a way that exposes rigid foam to moisture without proper drainage detailing. The crawl space stem wall provides R-2.5 where R-10 is required. For a high-performance house in a mixed-humid climate, these envelope failures undermine energy performance and durability.

3. **Scope Ambiguity and Missing Information:** Critical ambiguities exist regarding what is included in the base bid — most notably the solar array (shown as installed vs. specified as "ready"), numerous "TBD" selections without allowance amounts, and missing details for specialized systems (cable railings, pool installation sequencing, custom millwork fabrication). Contractors cannot price accurately when scope boundaries are unclear.

**Secondary Issues:** The set also exhibits internal inconsistencies (door schedule vs. plans, window manufacturer conflicts, abbreviation reuse), missing constructability details (valley flashings, handrail profiles, window rough opening waterproofing sequences), and incomplete coordination information (allowance values, testing requirements, shop drawing submittals).

The drawings demonstrate thoughtful design intent and appropriate detail for many conditions, but the coordination gaps and code violations require resolution before this set is suitable for competitive bidding or construction.
